# qa-core

Tests de extremo a extremo de aplicaciones web, con un navegador real.

## Contenido

- `skills/e2e-tests`: cómo se escribe un test de extremo a extremo.
- `mcp.json`: el servidor MCP de Playwright, con la versión fijada, para explorar la aplicación antes de escribir el test.

## Línea de dependencia

- qa-core
- dev-core
- common-core

## Frontera

Los tests unitarios siguen las reglas de `dev-core`. Este set es para recorridos completos en el navegador.
