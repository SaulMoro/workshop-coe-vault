# dev-core

Cómo se escribe y se cambia código, en cualquier lenguaje.

## Contenido

- `skills/dev-best-practices`: nombres, fallos y tamaño de un cambio, con una reference por tema.
- `skills/commit-messages`: mensajes de commit con Conventional Commits.
- `instructions/dev-tests.instructions.md`: reglas para los ficheros de test.

## Línea de dependencia

- dev-core
- common-core

## Frontera

Lo propio de un lenguaje va en su set (`dev-typescript`). Lo que no es código va en `common-core`.
