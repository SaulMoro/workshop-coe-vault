# front-ui-states

Estados de carga y de error, y accesibilidad, para listas React que leen datos del servidor.

- `skills/loading-states`: Suspense con un esqueleto que mantiene la forma de la lista.
- `skills/list-a11y`: nombre accesible y resumen para lectores de pantalla.
- `skills/api-errors`: errores de API comprensibles y reintento.
- `instructions/ui.instructions.md`: aplica list-a11y a archivos llamados `*List.tsx`.
- `agents/ui-reviewer.agent.md`: revisa en su propio contexto los estados de carga y de error de una página.

Los scripts de las skills buscan pistas en el texto; sus resultados no sustituyen una revisión del comportamiento.
