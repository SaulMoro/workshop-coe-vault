# front-core

El navegador, con cualquier framework: marcado, campos de formulario, imágenes y estilos.

## Contenido

- `skills/front-best-practices`: HTML semántico, campos de formulario e imágenes, con una reference por tema.
- `instructions/front-styles.instructions.md`: en los `.css`, los valores salen de los tokens del proyecto.

## Línea de dependencia

- front-core
- dev-typescript
- dev-core
- common-core

## Frontera

Lo propio de un framework va en su set (`front-react`). Los estados de carga, los errores de API y la accesibilidad de listas son del equipo que los define: este set no los cubre.
