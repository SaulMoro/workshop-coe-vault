# Clarify the task

Ask only when the readings lead to different changes. If they all lead to the same change, make it and say which reading you used.

1. Write down the readings you see, one line each.
2. Ask at most three questions in a single message. Give each question two or three options and mark the one you would pick.
3. Wait for the answer before you edit any file.
4. Repeat the decision in one line, then start.

Do not ask what the repository already answers. Read the code, the README and the existing tests first.
